# Reports

Audits, measurements, reviews, gate reports and process sources. **Frozen once written:** a re-measure or correction is a new dated file (`YYYY-MM-DD-<slug>.md`), so evidence never moves under a decision that cited it.

| Folder | Holds |
|---|---|
| `process/` | process documents adopted from elsewhere |
| `reviews/` | review-agent findings per task |
| `measurements/` | balance and performance measurements |
